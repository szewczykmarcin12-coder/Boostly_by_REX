# Dokumenty PDF - Boostly Popeyes

Ten katalog zawiera dokumenty PDF dla aplikacji Boostly.

## Struktura katalogów

Umieść pliki PDF w odpowiednich katalogach.
Nazwy plików powinny być w formacie: `nazwa-dokumentu.pdf` (małe litery, myślniki zamiast spacji).

## Przykłady:
- `documents/micros-symphony/instrukcja-obslugi-micros.pdf`
- `documents/brand-manual/zarzadzanie-restauracja/procedury-otwarcia.pdf`
- `documents/produkty/burgery/chicken-burger.pdf`
